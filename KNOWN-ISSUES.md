# Known issues

Backlog of broken elements in old articles, mostly damage from the
WordPress export. One section per post, one bullet per issue. Each bullet
names the issue type and a status:

- `fixable`: can be fixed by editing the post.
- `hard`: fixable only with significant effort (e.g. recovering an image
  from a web archive).
- `unfixable`: the original material is gone.

Whenever a broken element is found in an article, add it here. When one is
fixed, remove its bullet, and remove the section when a post is clean.
Images recovered but not yet placed into posts live in `recovered-images/`.
